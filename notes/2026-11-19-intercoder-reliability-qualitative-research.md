**Source:** [O’Connor and Joffe, “Intercoder Reliability in Qualitative Research: Debates and Practical Guidelines” (2020)](https://discovery.ucl.ac.uk/id/eprint/10091273/1/1609406919899220.pdf)

**Source keywords:** intercoder reliability, interrater reliability, qualitative analysis, interviews, coding

O’Connor and Joffe explain how coding works and outline a procedure for assessing intercoder reliability (ICR).

### 1. Coding units, codes, and the coding frame

In qualitative research, coding means assigning labels to portions of data that are relevant to the research.

- A coding unit is the portion being analysed, such as a phrase, sentence, paragraph, or meaningful passage. Its boundaries should fit the research aims and preserve enough context for interpretation.
- A code is a label assigned to a coding unit. For example, a review comment might receive the code “requesting technical assistance.”
- A coding frame is the organised set of codes, with definitions, examples, and rules for when to apply them. Depending on those rules, a unit may receive multiple codes.

### 2. What is ICR?

Intercoder reliability (ICR) is a numerical assessment of agreement between researchers who independently apply codes to the same data.

ICR helps assess whether researchers can apply a coding frame consistently. Agreement alone, however, does not show that their interpretations are correct or that the coding frame captures everything important.

### 3. Assessing disagreement and refining the coding process

Researchers independently code shared material and assess their agreement. They examine disagreements for possible ambiguities in code definitions, unit boundaries, or application rules.

They can then refine the coding frame or procedure and reassess agreement, preferably using different material. Agreement reached through discussion is distinct from independent agreement.
